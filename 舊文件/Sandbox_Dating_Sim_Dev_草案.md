# 沙盒戀愛模擬遊戲生成工具開發手冊草案 (v1.0)

## 1. 系統核心理念
本工具旨在復刻《同級生2》的沙盒探索感，並導入現代 AI 生成技術與高度自定義的邏輯框架。遊戲運行於「上午、下午、晚上」三段式時間軸，所有劇情推進均由「屬性權重」與「旗標（Flags）」驅動，捨棄隨機性，強調策略性與邏輯的一致性。

---

## 2. 第一階段：引導式變數設定精靈 (User Input Wizard)
工具介面將透過多步驟的引導式詢問，收集極其詳盡的世界觀參數。這些細節將構成後續生成腳本的底層邏輯。

### 步驟一：世界曆法與地理 (World Meta)
* **起始日期**：設定具體年月日（如：2026-04-27）。引擎將自動計算週休、季節與國定假日。
* **遊戲總時長**：設定天數（如：30、60、90天）。
* **地點清單**：定義地點名稱、性質（學園、商業區、貧民窟）及其基礎消費水平（Cost）。
* **重大事件預設**：在日曆中標註必須發生的事件點（如：祭典、考試、轉折點）。

### 步驟二：主角身分與基因 (Protagonist Blueprint)
* **身分識別**：性別、姓名、年齡、職業（影響初始金錢與名聲）。
* **初始數值包 (DNA)**：
    * **屬性**：智力 (INT)、魅力 (CHA)、勇氣 (STR)、道德 (MORAL)。
    * **經濟**：初始現金 (Cash)、負債 (Debt)。
* **性格與秘密**：決定 AI 生成對話時的主角語氣與潛在行為邏輯。
* **初始關係網**：定義開局時與特定配角（如損友、債主）的好感度與關係。

### 步驟三：角色矩陣 (Cast Matrix)
使用者可新增多位「可攻略角色」與「關鍵配角」：
* **性別與取向**：支援多樣化組合，AI 將據此調整稱謂與語氣。
* **社會功能**：職業、身分、在故事中的主要角色定位。
* **每日行程 (Schedule)**：定義角色在不同時間段（上午/下午/晚上）的出沒機率與預設地點。
* **隱藏秘密 (Secret Flags)**：設定角色不為人知的背景，需透過特定劇情解鎖。

### 步驟四：社會邏輯與生存壓力 (System Logic)
* **狀態標記系統 (Status Flags)**：取代傳統 HP。定義如「宿醉」、「過勞」、「被禁足」等狀態，用於強制鎖定玩家的時間段或移動權限。
* **運算加權邏輯**：定義性格標籤（如：傲嬌、冷酷）對不同行為類型（如：大膽、溫柔）的反應倍率。
* **客製化風格欄位**：提供自由輸入框，如「加入黑色幽默」、「對話中常帶有階級焦慮的社會評論」。

---

## 3. 第二階段：Mega-Prompt 生成引擎
當使用者完成上述步驟後，工具會自動將所有變數封裝成一個「高精密提示詞模板」，使用者只需將其複製並餵給外部 AI（如 Gemini, GPT-4）。

### 提示詞生成的關鍵要素：
1.  **語法規範指令**：強制 AI 產出符合引擎解析的 Markdown 標籤。
2.  **邏輯連貫性要求**：要求 AI 記住前幾天生成的 Flag，並在後續劇情中產生連鎖反應。
3.  **配角干預邏輯**：要求配角必須在主要劇情中扮演「干擾者」或「協助者」的角色。

---

## 4. 第三階段：Markdown (.md) 腳本規格定義
這是引擎識別的核心格式，確保 AI 產出的內容能直接被讀取與執行。

### 標籤語法範例：
| 標籤 | 說明 | 範例 |
| :--- | :--- | :--- |
| `# [地點]` | 定義場景地點 | `# 中央公園` |
| `## 條件` | 觸發門檻（時間與 Flag） | `## 條件: 下午 && Is_Met_GirlA == true` |
| `[Character]` | 資產調度（姓名, 服裝, 表情） | `[Character: 蘇菲, Costume: 私服, Emotion: 驚訝]` |
| `> [文本]` | 角色對話或旁白 | `> 蘇菲：「你...你怎麼會在這裡？」` |
| `- [選項]` | 分歧點與運算標記 | `- [送她禮物] {Type: Empathetic, Power: 3}` |
| `-> Result` | 執行結果與數值變動 | `-> Result: Sophie_Favor +5 && Cash -500` |
| `[Time_Cost]` | 額外消耗的時間段 | `[Time_Cost: 2]` |

---

## 5. 第四階段：資產管理與自動化清單
工具在解析 MD 檔後，會自動將「文字描述」轉化為「素材清單」。

* **圖像管理系統**：
    * 自動抓取 `Character + Costume + Emotion` 標籤。
    * **智能重命名**：使用者上傳圖片後，工具自動更名為 `CharName_Costume_Emotion.png`。
    * **Y 軸對齊工具**：介面提供基準線，使用者可手動微調圖片偏移量，確保角色在畫面上的高度統一。
* **音訊管理系統**：
    * 列出腳本中出現的 `BGM` 指令。
    * 設定循環播放 (Loop) 或單次播放的邏輯。

---

## 6. 第五階段：整合主控台與除錯 (Dashboard & Debug)
* **劇情樹狀圖 (Flowchart)**：自動將網狀劇本視覺化，標註出所有分歧點與 Flag 指向，方便檢查邏輯死路。
* **自動除錯器 (Linter)**：匯入 MD 檔時，自動檢查是否有標籤語法錯誤、地點 ID 不符或角色遺漏。
* **一鍵預覽**：提供模擬播放器，讓開發者在正式打包前快速測試特定時間點的事件觸發。

---

## 7. 後續細節與進階規劃
* **性別動態替換**：引擎將根據 `PROTAG_GENDER` 自動調整劇本中的代名詞。
* **多語言擴充**：支援透過 AI 快速翻譯 Markdown 腳本，保留邏輯標籤不變。
