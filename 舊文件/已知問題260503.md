### 2. 新增表單驗證失敗後清空使用者已輸入內容

問題描述：

- 目前多個新增表單使用：

  ```python

  ```

- Streamlit 的 `clear_on_submit=True` 會在按下 submit 後清空表單 widget，不會區分這次 submit 是成功新增或驗證失敗。

- 正確 UX 應為：驗證失敗只顯示錯誤並保留目前輸入，讓使用者修正 ID 後再次提交。

影響範圍：

- `src/sandbox_dating_sim/ui/streamlit_uiw.py`
- 已確認相關表單包含：
  - `add_character`

- 其他使用 `clear_on_submit=True` 且有驗證需求的新增表單也應一併檢查。

處理結果：

- `add_character`、`add_ending`、`add_location` 已改為 `clear_on_submit=False`。
- 表單欄位已使用明確 draft keys 保存輸入。

- 新增成功後才手動清除該表單 draft keys，append canonical data，然後 `st.rerun()`。
